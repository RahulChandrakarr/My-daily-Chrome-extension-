        Summary

          Contributions

          Why isn't a push showing here?

          These are the squares from your GitHub profile, and GitHub decides what counts. A commit counts when:

          • it was made with an email address linked to your GitHub account (in that repo, git config user.email shows which one),
          • it's on the repository's default branch, usually main. Commits on other branches count once they're merged,
          • the repository isn't a fork,
          • for private repositories, "Include private contributions" is on in your GitHub profile settings.

          New contributions can take a little while to appear.
